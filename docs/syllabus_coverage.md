# 与课程内容的对应关系

课程要求：*"Use machine learning methods taught in AIT201. Other suitable traditional machine
learning methods may be used with proper understanding and justification. Deep learning methods
not covered in this course are not allowed."*

这份对照表的作用是把"我们用了什么"逐项挂到 W1–W14 上：哪里是直接用的课堂方法，
哪里是课堂之外的传统方法（需要论证），哪里是课讲了但我们没用的。

---

## 1. 逐周对照

| 周 | 课程内容 | 本项目的对应 | 状态 |
|---|---|---|---|
| **W1** | ML 基础概念、问题形式化（T/P/E）、Python | T = 预测 t+3h 的 PM2.5 等级；P = 模型输出的四级概率与浓度；E = 六项指标 + 非对称代价。整个流程用 Python/sklearn 实现 | ✅ 直接使用 |
| **W2** | 分类、监督 / 无监督、聚类、数据科学问题 | 有序四分类是分类问题；全流程为监督学习；无监督部分用模糊 C 均值（FCM）对滑动窗口做形态聚类 | ✅ 分类与监督学习直接用；FCM 是聚类的延伸（见 §2） |
| **W3** | 数据采集、预处理、特征工程、缩放、降维、模型选择 | ① Open-Meteo API 采集 26 个格点 51 个月逐小时数据；② 缺失插值（≤3h）、越界校验、去重、时间网格重建；③ 滞后 / 滚动 / 周期正余弦 / 上风向传导特征；④ FCM 前的窗口归一化；⑤ 互信息、RFE、permutation importance 做特征选择；⑥ 逐节点时序切分 | ✅ 全覆盖（"降维"只用了特征选择，未用 PCA，见 §3） |

| **W9** | 网络结构、感知机、激活函数、前馈 ANN | 未使用 | — 不适用（本项目不走深度学习） |
| **W10** | MLP、反向传播、优化、梯度下降、TensorFlow | 未使用 | — 不适用 |
| **W11** | 贝叶斯推断、先验 / 似然 / 后验、MAP、朴素贝叶斯 | 未使用 | — 可选补充 |

## 2. 课堂之外的传统方法（需要论证的 6 项）

课程允许"其他合适的传统机器学习方法"，前提是**理解清楚并给出理由**。
下面 6 项不属于 W1–W14 的教学内容，全部是传统方法、没有一项是深度学习，因此不违反禁令，
但报告中必须逐项论证。按风险从高到低排：

| # | 方法 | 用在 | 为什么课堂之外 | 论证策略 |
|---|---|---|---|---|
| 1 | **GPSO 分组交换粒子群** | 6 号：非对称代价阈值寻优 | W10 讲的是梯度下降，不是群智能优化 | 单独一节给出速度/位置更新式与跨组交换算子；**必须与网格搜索 / 随机搜索做同预算对比**，证明它值这个复杂度，否则就是为炫技而炫技 |
| 2 | **SHAP 归因** | 6 号：白盒解释 | 课程只讲特征重要性，不讲博弈论归因 | 定位成"模型解释工具"而非"新模型"；用课内的 permutation importance 做对照，说明两者结论是否一致 |
| 3 | **非对称代价敏感学习** | 6 号：代价矩阵 | W4 讲混淆矩阵与指标，不讲代价敏感决策理论 | 从混淆矩阵出发推导期望代价，说明"为什么准确率在这里是错的指标"；与 class_weight 的 Balanced RF 对比 |
| 4 | **有序随机森林（累积二分类分解）** | 5 号：M4 | 课程只讲名义多分类 | 说明四等级有次序、名义分类会丢信息；给出保序修正的必要性；与 M2B 在同一特征上对比 |
| 5 | **分位数随机森林** | 5 号：M5 | 课程不讲区间预测 | 用随机森林叶节点经验分布解释，落到 W6 的树结构上；用 PICP/MPIW 评价，不用生僻指标 |
| 6 | **模糊 C 均值（FCM）** | 3 号：窗口形态聚类 | W2 讲聚类，但没讲模糊聚类 | 承认它是 K-means 的模糊化扩展，给出隶属度公式；说明为什么硬聚类在这里不合适（形态是渐变的） |

**风险集中点**：6 号一个人负责的 3 项全部超纲。答辩时最可能被追问的就是"这三个方法哪来的"。
建议 6 号在报告里专门写一节 *Beyond the Syllabus: Justification*，把这三个连同 SHAP 一次性讲清楚。

## 3. 课程讲了但我们没用的（4 项）

这几项不是错误，但补上能明显提升"用了课堂方法"的观感，而且成本很低：

| 缺口 | 所在周 | 补的代价 | 建议 |
|---|---|---|---|
| **Boosting（AdaBoost / GradientBoosting）** | W7 | 低。数据与评估都现成，几十行 | **最该补**。W7 明确讲 boosting，我们 6 个模型里一个 boosting 都没有，评审一眼能看出来。作为第 7 个基线加进 4 号的模型矩阵，成本几乎为零 |
| **ROC / AUC** | W4 | 低。把 Level 2+3 合成"高危 vs 非高危"二分类，画一条 ROC | 建议补在高危预警的补充评估里。注意：多分类 ROC 会引入额外复杂度，用二分类版本最稳妥 |
| **PCA 降维** | W3 | 中。要重跑一轮对比 | 可选。现在的"降维"其实是特征选择（互信息 / RFE），不是投影。在报告里把话说清楚即可，不必强行加 |
| **KNN / SVM / 朴素贝叶斯** | W5 / W8 / W11 | 中 | 不建议补。这三个是在不同假设下的对照模型，与本项目"时序 + 有序"的设定不贴合，硬塞反而显得凑数 |

## 4. 结论

1. **主体现有实现（1 号已交付的部分）100% 在课程范围内**：
   决策树（W6）、GridSearchCV + TimeSeriesSplit（W4/W5）、混淆矩阵与 Recall（W4）、
   特征工程与缺失处理（W3）。没有任何一项需要额外论证。

2. **后续 4 个模块里有 6 项课堂之外的方法**，全部是传统方法、无深度学习，
   属于课程允许的"其他合适方法"，但必须在报告中逐项论证，且要说明"为什么课堂方法不够用"。
   最容易出问题的是 GPSO——它听起来最像自创算法，必须用同预算对比证明其必要性。

3. **两个低成本补强**：加一个 boosting 模型（W7）、加一条高危二分类 ROC（W4）。
   这两项加起来不到半天工作量，但能把"7 周直接覆盖 / 2 周部分覆盖"变成
   "8 周直接覆盖 / 1 周部分覆盖"。

4. **不要为了凑覆盖面硬加 KNN / SVM / 朴素贝叶斯**。课程评的是"用得对不对、解释得清不清楚"，
   不是"模型数量"。塞一个和问题不贴合的模型，答辩时反而多一个被问倒的点。
