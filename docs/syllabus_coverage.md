## 2. 保留的唯一一项课堂外方法

| 方法 | 谁 | 是什么 | 为什么留 |
|---|---|---|---|
| **有序随机森林**（累积二分类分解） | 5号：M6 | 把四分类拆成 3 个累积二分类 P(Y>0)、P(Y>1)、P(Y>2)，训练 3 个 RF，保序修正后差分还原四类概率 | 它不是锦上添花，而是**直接打在基线暴露的缺陷上**：现有决策树把 1,348 个真实 Level 2 判成 Level 1、758 个真实 Level 3 判成 Level 2，属于系统性低报。名义分类器分不清"差一级"和"差三级"，有序分解是目前唯一的解法 |

**论证方式**（报告里要写清楚，不能含糊）：

1. **说明问题**：四级等级有序，名义多分类把相邻等级当成互不相关的类别，丢了次序信息。
2. **用数据证明代价**：拿基线的混淆矩阵指出，错误集中在相邻等级之间（L2→L1、L3→L2），
   正是不尊重次序的典型症状。
3. **给出课内对照**：**M5（回归→阈值切档）已经用回归的连续性隐式保序**，属 W2/W7 范围。
   M5 与 M6 是同一问题的两条解法，谁更好由 MAOE 与跨级误判率实测决定。
4. **接受不利结果**：如果 M6 相对 M5 没有显著优势，就如实写"有序分解在本数据上增益有限，
   回归分级已足够"——这本身是有价值的负结果。

保留它的底线：**只用 sklearn 的 RandomForestClassifier，不引入新库、不引入新概念**
（累积概率、保序、差分都是课堂内容的组合）。

## 3. 删掉的 4 项，以及换成了什么

这 4 项原本都在方案里，逐项评估后判定"超纲且非必要"，全部替换为课内等价做法。
替换后效果多数情况下不比原方案差，而且答辩更好讲。

| 原方案 | 为什么删 | 换成什么 | 课内依据 |
|---|---|---|---|
| **GPSO 分组交换粒子群** 搜阈值 τ | 群智能优化不在课程内，W10 讲的是梯度下降；名字最容易被追问"哪来的"；更关键的是——**为了搜三个阈值就引入一个进化算法，成本与收益不成比例** | **在验证集上对 τ=(τ1,τ2,τ3) 做网格搜索**，目标函数仍是最小化平均非对称代价；配一张 ROC 辅助选工作点 | W4：调参、混淆矩阵、ROC |
| **SHAP** 归因 | 博弈论归因不在课程内，还依赖外部库；课程已经讲了特征重要性 | **permutation importance**（打乱某列看指标掉多少）+ **部分依赖图 PDP**（单变量与预测的关系） | W3 / W6 / W7：特征重要性 |
| **分位数随机森林**（quantile-forest） | 需要额外依赖；区间预测与 PICP/MPIW 都不在课程内 | **用森林里每棵树的预测值取 5% / 50% / 95% 分位**得到预测区间——这正是 bagging 的副产品 | W7：集成、bagging |
| **模糊 C 均值 + 隶属度 + 解粒化重构** | 模糊聚类与"粒化—解粒化"是课程外的概念堆叠；而且它想论证的"形态异常度"与滚动统计高度重叠，属于为新颖而新颖 | **只保留区间粒化与趋势粒化**：窗口的下界、中枢、上界、宽度、最小二乘斜率。本质就是窗口统计量 | W3：特征工程 |

## 4. 结论

1. **主体现有实现（1 号已交付）100% 在课程范围内**：决策树（W6）、GridSearchCV +
   TimeSeriesSplit（W4/W5）、混淆矩阵与 Recall（W4）、特征工程与缺失处理（W3）。
2. **删减后只剩 1 项课堂外方法**（有序随机森林），它有明确的课内对照 M5、明确的问题指向
   （基线系统性低报），论证成本可控。
3. **补上 boosting 与 ROC 后，W4 与 W7 从"部分覆盖"变成"完全覆盖"**，两项加起来不到一天。
4. **不做的事**：不补 SVM（W8）、朴素贝叶斯（W11）、KNN（W5）、PCA。
   它们与"时序 + 有序"的设定不贴合，硬塞只会多一个被问倒的点。
   课程评的是用得对不对、讲得清不清楚，不是模型数量。
